# Food Ordering App

A responsive and feature-rich food ordering platform, enabling users to explore and order from a wide range of restaurants. The app includes features like restaurant filtering, sorting, and displaying promoted restaurants with a special label.

---

## 📋 **Description**

This is a modern food ordering application built using **React**. It features a restaurant listing system that fetches data from a local API and displays a variety of restaurants along with their details. The app also allows users to filter, sort, and view promoted restaurants in a dynamic way.

---

## 🛠️ **Features**

- **Responsive UI**: Optimized for mobile and desktop views.
- **Restaurant Filters**: Users can filter by Relevance, Delivery Time, Rating, and Cost (Low to High/High to Low).
- **Promoted Restaurants**: Restaurants that are promoted appear with a special label.
- **Hero Section**: A visually appealing hero section that appears at the top of the home page.
- **API Integration**: Fetches restaurant data from an API and displays it dynamically.
- **Sorting**: Users can sort restaurants based on different parameters.

---

## ⚙️ **Technologies Used**

- **React**: Frontend framework for building user interfaces.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **React Router**: Used for managing routes and navigation within the app.
- **JavaScript/ES6**: Scripting language used for all functionality.
- **Fetch API**: Used for fetching restaurant data from the server.
- **Higher Order Components (HOC)**: To add special functionality like promoting a restaurant.
